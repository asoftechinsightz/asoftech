# AsoftechInsightz

Corporate marketing website for **AsoftechInsightz** — Enterprise Technology Consulting | Digital Engineering | AI Automation | SaaS Products.

> Technology. Intelligence. Growth.

## Quick start

```bash
npm install
npm run dev
```

See [docs/local-development.md](docs/local-development.md) for scripts, env vars, and form behaviour.

## Monorepo

- `apps/marketing` — Next.js App Router site
- `packages/design-tokens` — brand colours + Tailwind preset
- `packages/validation` — shared Zod schemas
- `docs/` — architecture, sitemap, design system, local run
- `infrastructure/` — nginx/docker stubs for later **manual** Hostinger deploy (not applied)
